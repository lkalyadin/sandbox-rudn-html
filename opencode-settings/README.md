# opencode-settings

Проект для работы с настройками основного стенда разработки
`https://94.141.97.249:4601` (OpenCode 2.0.32 + Caddy, systemd user-юниты на этом же хосте).

- **`AGENTS.md`** — главное: что развёрнуто, ограничения хоста (1 vCPU / 1.6 ГБ, docker
  выключен), риски, команды, правила правок, чек-лист «стенд жив».
- **`docs/snapshot-2026-10-28.md`** — фактический снимок: порты, юниты, TLS, провайдеры,
  модели, конфиги, состояние БД. Сверяться с ним перед правками.
- **`docs/migration-runbook-2026-10.md`** — переезд на новый VPS: что переносить, как поднять
  стенд с нуля, TLS силами Caddy (без certbot), проекты, студенческий стенд на отдельной VPS,
  проверки и откат.
- **`scripts/export-main-stand.sh`** — экспорт конфигов/проектов/БД в один архив для переезда
  (`--dry-run` — только план).

Студенческие/демо-стенды (docker, edge, изоляция, датасеты, лимиты моделей) — проект
`../students/`, его контекст в `../students/AGENTS.md`.
