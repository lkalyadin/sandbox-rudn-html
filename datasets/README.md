## Микро-данные: респонденты, клиенты, товары

### `bank.csv` — 4521 строк, 451 КБ

Отклик клиентов на депозитную кампанию банка. Разделитель `;` (!). Измерения: job, marital, education, contact, housing, loan, month, poutcome; показатели: age, balance, duration, campaign, previous, y.

**Осторожно:** Нет ID клиента → строки не уникальные люди; года нет → `month` не временной ряд; `balance` — среднегодовой баланс, не доход кампании; `duration` известна после контакта.

### `wholesale_customers.csv` — 440 строк, 15 КБ

Оптовые клиенты дистрибьютора: канал (HoReCa / розница) и регион против годовых расходов по 6 категориям (Fresh, Milk, Grocery, Frozen, Detergents_Paper, Delicassen).

**Осторожно:** Денежные суммы без валюты и периода в самом файле — это годовые расходы, не выручка; масштабы категорий несопоставимы между собой.

### `car_evaluation.csv` — 1728 строк, 51 КБ

Оценка автомобиля по 6 признакам: buying, maint, doors, persons, lug_boot, safety → класс (unacc / acc / good / vgood). Без заголовков.

**Осторожно:** Это синтетическая экспертная шкала, а не рыночные цены: доли классов нельзя читать как долю рынка.

меньше стран (госдолг, бедность, Джини) — фильтруйте до сравнения.

**В этих файлах лежат не только страны.** Кроме ~200 стран, в колонке `country`
есть 42 макроагрегата Всемирного банка: `World`, `Euro area`, `OECD members`,
`Sub-Saharan Africa`, `East Asia & Pacific`, `High income`, `IDA only` и т. п.
Если их не отбросить, рейтинг стран получается ложным: «World» будет на первом
месте, рядом со Германией окажется «East Asia & Pacific».

Готовый фильтр — `python3 /opt/viz/kit/wb.py` (модуль, не CLI):

```python
import sys; sys.path.insert(0, "/opt/viz/kit")
from wb import load, rows
df = load("wb_unemployment.csv")     # country, country_code, year, value, is_country, region
df = df[df["is_country"]]            # 42 агрегата отброшены, регион добавлен
```

Коды агрегатов — официальный список банка (WLD, EUU, EAS, …), поэтому фильтр
не зависит от названий и переживает «Egypt, Arab Rep.». У стран разные
последние годы (2015–2023), поэтому «год = 2023» молча выбрасывает часть
выборки: для «последнего доступного» используйте `wb.add_last_flag(df)`.

## Правила работы с данными

- Не меняйте файлы в `data/`: они общие для всех и физически только для чтения.
- Всегда говорите, сколько строк попало в расчёт и сколько выброшено.
- Для денежных величин указывайте валюту и год.
