Инструкция
  1. В каждом вопросе выберите один правильный ответ и обведите его букву.
  2. За правильный ответ — 1 балл, за неправильный — 0. Максимум — 12 баллов.
  3. Пользоваться конспектами и ИИ-сервисами нельзя.
  4. Если вопрос кажется неоднозначным, выбирайте ответ, наиболее близкий к формулировкам лекции.
01ИИ · ДАННЫЕ

Что отправить в чат

Нужно, чтобы ИИ помог разобрать CSV на 180 000 строк. Что разумнее отправить в чат на первом шаге?

  1. AВесь файл целиком — так модель увидит все исключения.
  2. BТолько названия столбцов без примеров значений.
  3. CСкриншот первых строк таблицы.
  4. DЗаголовки, 5–20 характерных строк (обычные и проблемные), описание полей, целевые типы и правила проверки.
02ИИ · ДАННЫЕ

Персональные данные в чате

Студент хочет построить график по выгрузке с ФИО, телефонами и суммами заказов и собирается отправить весь файл в публичный чат-бот. Что нужно сделать прежде всего?

  1. AУбрать или обезличить персональные данные и получить разрешение на отправку; при возможности отправить агрегаты.
  2. BПереименовать файл в .txt.
  3. CСжать файл в архив.
  4. DПопросить бота не сохранять данные.
03ИИ · ДАННЫЕ

ИИ видит число, а не смысл

В фрагменте есть столбец id со значениями 001042, 001043. ИИ предлагает преобразовать его в число. Почему это опасно и что добавить в запрос?

  1. AОпасно только для больших чисел; ничего добавлять не нужно.
  2. BЧисловой тип удобнее для сортировки, поэтому предложение верное.
  3. CЭто идентификатор: ведущие нули потеряются; в запросе нужно указать «id — текст, арифметику не выполнять».
  4. DНужно удалить столбец id, чтобы не мешал.
04ИИ · ЗАПРОС

Запрос на преобразование JSON

Нужно превратить небольшой JSON с заказами и массивом товаров в таблицы. Какой запрос к ИИ даст проверяемый результат?

  1. A«Сделай из этого JSON красивые таблицы».
  2. B«Сделай таблицы "Заказы" и "Товары": id — текст, сумма — число, дата в формате ГГГГ-ММ-ДД, для items — отдельная строка на товар; покажи число строк и перечисли поля, которые нельзя преобразовать однозначно».
  3. C«Преобразуй JSON в Excel, чтобы всё было удобно».
  4. D«Разбери JSON и скажи, нет ли здесь ошибок».
05ИИ · ПРОВЕРКА

Позиции не потерялись?

ИИ развернул JSON с заказами и товарами в две таблицы. Какой набор проверок лучше всего покажет, что позиции не потеряны?

  1. AОткрыть обе таблицы и посмотреть, «выглядят ли они нормально».
  2. BПроверить, что в таблицах нет пустых ячеек.
  3. CПопросить ИИ подтвердить, что он ничего не потерял.
  4. DСравнить число заказов и товаров до и после, сверить контрольные суммы и проверить несколько заказов с несколькими позициями.
06ИИ · ПРОВЕРКА

Код запускается — достаточно ли

ИИ написал код, который считает выручку по месяцам и каналам. Код запускается без ошибок. Что ещё обязательно проверить?

  1. AЧисло строк, суммы, дубликаты и несколько вручную пересчитанных примеров.
  2. BЧто код написан в одну строку.
  3. CЧто использованы функции последней версии библиотеки.
  4. DЧто ИИ объяснил каждую строку кода.
07ИИ · ПРОВЕРКА

Сумма долей не сходится

После агрегации ИИ сумма по каналам составила 96% от общего итога. Что делать?

  1. AОпубликовать: 4% — допустимая погрешность округления.
  2. BУвеличить наибольший сегмент на 4%, чтобы сумма сошлась.
  3. CНайти причину расхождения: потерянные строки, дубли, фильтры или разные базы; до этого вывод не публиковать.
  4. DУдалить общий итог из отчёта.
08ИИ · ВИЗУАЛИЗАЦИЯ

Средний чек на дашборде

ИИ построил дашборд, но средний чек получился заметно ниже ожидаемого. В данных строка — позиция заказа. Что вероятнее всего?

  1. AИИ неправильно выбрал цвета.
  2. BИИ усреднил суммы по позициям, а не по заказам; нужно сначала агрегировать до заказа.
  3. CВ данных слишком много столбцов.
  4. DНужно перейти с линейной диаграммы на круговую.
09ИИ · ВИЗУАЛИЗАЦИЯ

Рост «почти в три раза»

ИИ пишет: «выручка выросла почти в 3 раза». На графике ось Y начинается с 90, а значения выросли с 95 до 100. Что проверить в первую очередь?

  1. AПалитру и подписи данных.
  2. BКоличество категорий на графике.
  3. CИсточник данных.
  4. DБазу и масштаб оси: при начале не с нуля визуальный рост преувеличен; сравнить абсолютные значения.
10ИИ · ВЫВОД

Сезонность по трём месяцам

ИИ пишет: «Падение в марте объясняется сезонностью». В данных только три месяца — январь, февраль, март. Как оценить утверждение?

  1. AНе принимать как вывод: по трём месяцам нельзя установить сезонность, нужна история за несколько лет.
  2. BПринять: ИИ знает типичные сезонные паттерны.
  3. CПринять, если падение больше 10%.
  4. DЗаменить «сезонность» на «тренд» — так точнее.
11ИИ · ВЫВОД

Уверенно, но без доказательств

ИИ уверенно называет долю крупнейшей категории — 47%, но не показывает ни формулы, ни ячеек. Какое действие соответствует AI-аудиту?

  1. AПринять: число выглядит правдоподобно.
  2. BПопросить ИИ повторить ответ более уверенно.
  3. CПотребовать доказательство: формулу, диапазон ячеек или расчёт, и независимо пересчитать.
  4. DОкруглить до 50% и указать «примерно».
12ИИ · ВЫВОД

Зачем вести AI-лог

Зачем в паспорт задачи и AI-аудит записывают промпт, версию модели, исправления кода и ограничения данных?

  1. AЧтобы чат-бот работал быстрее.
  2. BЧтобы результат можно было воспроизвести и независимо проверить, а границу вывода — объяснить.
  3. CЧтобы не проверять расчёты повторно.
  4. DЧтобы заменить этим раздел с выводами.
