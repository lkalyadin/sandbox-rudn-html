Памятка · JSON, XML и графики

1 · JSON

Объект — фигурные скобки, массив — квадратные. Шесть типов: строка, число, логическое, null, объект, массив. Ключи должны быть уникальны; после последнего элемента запятая не ставится.

null ≠ отсутствие ключа: это разные состояния, и сравнение null с числом не даёт истины.

2 · XML

Один корневой элемент. Данные могут быть в дочерних элементах или в атрибутах; атрибуты при разборе в таблицу нужно извлекать явно. Служебные символы вроде амперсанда экранируют или прячут в CDATA.

XSD задаёт типы и допустимую форму: xs:date — ГГГГ-ММ-ДД, xs:decimal — точка без разделителя тысяч.

3 · JSON / XML → таблица

Сначала решите, что станет строкой. Повторяющийся элемент или массив → несколько строк, а поля родителя повторяются. Для больших файлов нужен потоковый разбор, а не загрузка всего в память.

4 · Тип графика

Сравнение — столбцы; структура — круг или накопленные столбцы; динамика — линия; распределение — гистограмма; связь — точечная; две категории — тепловая карта; место в вопросе — карта.

ВОПРОС → ДАННЫЕ → ФОРМА → ПРОВЕРКА
Форма хороша, если по ней можно сформулировать ответ.
Точное значение — таблица. Круг — для простого целого с малым числом частей. Линия — для времени, а не для произвольных категорий.
