# Kit — конструктор дашборда (`/opt/viz/kit`)

Готовый движок страницы для задачи «аналитический one-page дашборд».
Требования Skill.MD §2–§7 (две иконки, панель настроек с двумя вкладками,
наследование настроек, Top N и «Остальные», сохранение автономного HTML, блок
Skill.MD, автопроверка) уже реализованы и протестированы. Вам нужно описать
задачу и подготовить данные — не писать 50 КБ JavaScript.

## Быстрый путь (типовая задача по World Bank)

```sh
cd "$TASK"
python3 /opt/viz/kit/examples/wb_country.py \
    --csv wb_gini.csv \
    --title "Неравенство по странам: индекс Джини" \
    --question "В каких странах неравенство выше и как оно менялось в 2015–2023?" \
    --out output/dashboard.html

python3 /opt/viz/check_page.py output/dashboard.html       # ошибки JS и внешние ссылки
python3 /opt/viz/kit/verify_page.py output/dashboard.html  # фильтры, отбор, темы, импорт
python3 /opt/viz/screenshot.py output/dashboard.html --out preview.png
```

Файл `examples/wb_country.py` — это шаблон: скопируйте его в `$TASK`, поменяйте
подписи и графики. `examples/bank_share.py` показывает второй случай — расчёт
доли (`share`) и знаменатель в тултипе.

## Свой spec.json

```sh
python3 /opt/viz/kit/dashboard.py --spec spec.json --out output/dashboard.html
```

```json
{
  "title": "Безработица по странам",
  "question": "Где безработица выше и как она менялась?",
  "theme": "almanac",
  "decimals": 1,
  "source": "wb_unemployment.csv (World Bank)",
  "note": "Агрегаты банка исключены.",
  "data": {"columns": ["country", "year", "value"],
           "rows": [["Германия", 2015, 4.6], ["Германия", 2016, 4.1]]},

  "dimensions": {
    "country": {"label": "Страна"},
    "year":    {"label": "Год", "ordered": true}
  },
  "measures": {
    "value": {"label": "Безработица", "column": "value", "unit": "%", "agg": "mean"},
    "count": {"label": "Наблюдений", "agg": "count", "column": "country"}
  },
  "kpis": [
    {"label": "Стран", "agg": {"fn": "count_distinct", "column": "country"}, "decimals": 0},
    {"label": "Медиана", "agg": {"fn": "median", "column": "value"}, "unit": "%"}
  ],
  "filters": [
    {"id": "year", "label": "Год", "column": "year", "default": "last"}
  ],
  "charts": [
    {"id": "top", "title": "Топ-15", "type": "hbar", "dimension": "country",
     "measure": "value", "topN": 15, "rest": "mean"}
  ]
}
```

### Поля

| Поле | Обязательно | Значение |
|---|---|---|
| `title`, `question` | да | заголовок и аналитический вопрос страницы |
| `theme` | нет | `almanac` (по умолчанию), `console`, `coral`, `furrow` |
| `decimals` | нет | знаков после запятой по умолчанию (0–4, обычно 1) |
| `source`, `note` | нет | подпись источника и оговорка под графиками |
| `data` | да* | `{columns, rows}` **или** список словарей (по ключу на колонку) |
| `data_file` | да* | путь к JSON с `{columns, rows}` вместо `data` |
| `dimensions` | да | по чему группируем: `{"колонка": {"label": "...", "ordered": true}}` |
| `measures` | да | что считаем: `{"ключ": {"label", "column", "unit", "agg", "equals"}}` |
| `kpis` | нет | 3–4 показателя: `{"label", "agg": {"fn", "column"}, "decimals", "unit", "subBy"}` |
| `filters` | нет | не больше 3: `{"id", "label", "column", "default": "last", "valueLabels": {...}}` |
| `charts` | да | не больше 6: см. ниже |
| `skill` / `skill_path` | нет | текст Skill.MD; по умолчанию берётся `/etc/opencode/skills/economist-sandbox/SKILL.md` |

`ordered: true` у измерения означает «естественный порядок» (годы, интервалы):
только для него разрешена линия, и без Top N.

### Агрегаты (`agg` / `agg.fn`)

| Значение | Что считает |
|---|---|
| `mean`, `sum`, `min`, `max`, `median` | обычные функции по строкам группы |
| `first`, `last` | первое/последнее значение в группе (для изменения за период) |
| `count` | число строк |
| `count_distinct` | число различных значений колонки (например, стран) |
| `share` | доля строк, где `column == equals` (плюс `pos`/`den` в тултипе) |

### Графики

```json
{"id": "уникальный", "title": "...", "type": "hbar|vbar|line|table",
 "dimension": "ключ из dimensions", "measure": "ключ из measures",
 "topN": 15, "rest": "mean", "sort": "asc|desc|dim", "note": "..."}
```

* `hbar` / `vbar` — категории; `line` — только `ordered`-измерение и без `topN`
  (несовместимый тип движок заменит сам);
* `table` — таблица «категория, значение, строк»;
* `topN` + `rest` — хвост сворачивается в «Остальные (n)» **по исходным строкам**
  (среднее объединённых строк, не среднее из средних), как требует §5;
* `sort: "dim"` — по порядку измерения (для интервалов и годов);
* `note` — мелкая оговорка под карточкой (единицы, ограничения данных).

## Что уже сделано за вас

* Верхняя панель: только дискетка (сохранить HTML) и шестерёнка (настройки),
  область нажатия ≥44 px, `title` и `aria-label`.
* Панель настроек: вкладки «Общие» и «Графики», наследование (`null` —
  наследовать), скрытие без удаления настроек, сброс переопределений,
  JSON-экспорт/импорт с валидацией (без `eval` и `__proto__`), Escape закрывает.
* Клик по столбцу/строке — общий отбор для всех блоков, повторный клик снимает;
  Enter/Space работают; тултип есть и на наведении, и на фокусе.
* KPI считаются по текущему отбору, под ними видно «строк в отборе».
* Пустая выборка — сообщение и кнопка сброса.
* Тёмная тема, системные шрифты, `prefers-reduced-motion`, никаких внешних
  запросов; всё внутри одного файла, работает через `file://`.
* Блок «Skill.MD» внизу страницы с полным текстом и скачиванием.

## Ограничения (Skill.MD §10.4)

Не больше **6 графиков**, **3 фильтров**, **4 KPI**, **100 000 строк** в
странице. Раскладка подстраивается под число карточек: 4 графика — честные 2×2,
3 — в один ряд, 5–6 — по три, 1–2 — по числу; карточки в ряду одной высоты. Сборщик сам откажется собирать страницу с превышением и скажет, что
именно свернуть. Если строк больше — агрегируйте в Python и оставьте нужные
разрезы.

## Проверки перед выдачей ссылки

```sh
python3 /opt/viz/check_page.py "$TASK/output/dashboard.html"
python3 /opt/viz/kit/verify_page.py "$TASK/output/dashboard.html"
python3 /opt/viz/screenshot.py "$TASK/output/dashboard.html" --out "$TASK/preview.png"
```

Один прогон достаточно. Не пишите собственные тестовые фреймворки с
многократным запуском браузера: `verify_page.py` уже проверяет фильтры, клик,
скрытие графиков, тёмную тему и отклонение невалидного конфига.

## Если нужен нестандартный график

Скопируйте `engine.js` и `template.html` в `$TASK`, добавьте свой тип графика
и собирайте страницу своим скриптом (как `dashboard.py`). Остальные правила
(настройки, сохранение, Skill.MD) при этом остаются выполненными.

## Для разработчика kit

После правок `engine.js`/`template.html` прогоните сценарий, который не входит
в обычную проверку агента:

```sh
python3 /opt/viz/kit/dev/roundtrip_probe.py "$TASK/output/page.html"
```

Он проверяет открытие панели, «Отмена», сохранение автономного HTML и повторное
открытие сохранённого файла (в том числе сохранённую тёмную тему).
