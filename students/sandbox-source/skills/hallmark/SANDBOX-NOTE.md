# Hallmark в песочнице стенда — что здесь есть и как это читать

Копия [github.com/Nutlope/hallmark](https://github.com/Nutlope/hallmark) (ветка `main`,
снята 2026-10-27), примонтирована только для чтения в `/opt/hallmark`.

## Что есть

| Путь | Зачем |
|---|---|
| `SKILL.md` | «The Floor» — жёсткие правила, и Flow — порядок работы |
| `references/flow.md` | раздел **App screens** — это наш случай (рабочий аналитический экран) |
| `references/redesign.md` | что делать, если студент просит переделать готовую страницу |
| `references/themes/index.json` | каталог 40 тем: жанр, материал, ключевые слова |
| `references/themes/<slug>.md` | сама тема: готовые `tokens.css`, типографика, правила |
| `references/layout.md`, `craft.md`, `data-viz.md`, `interaction-and-states.md`, `gates.md` | раскладка, ремесло, графики, состояния, проверки |
| `references/macrostructures/*.md` | композиции экрана |

## Чего нет (сознательно)

- **изображений тем (`*.jpg`)** — они нужны человеку для превью, агенту не нужны;
- **каталога `scripts/`** — в песочнице нет node, поэтому `sloplint --render` недоступен.
  Вместо него обязательна браузерная проверка `python3 /opt/viz/check_page.py <файл>`;
  нельзя называть её «sloplint пройден».
- **интернета**: шрифты только системные, внешние загрузки запрещены.

## Приоритет правил

Требования студента и автономность → `SKILL.md` стенда → Hallmark.

Hallmark — источник направления дизайна, а не повод превратить аналитический экран
в лендинг. Из него берём: The Floor, токены, ограниченный контейнер, типографическую
шкалу, «одна идея на экран», выбор темы.
