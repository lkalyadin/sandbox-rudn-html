# Демо: агентная разработка на данных

Вы работаете в браузере. Ничего устанавливать не нужно.

OpenCode — это агент: он сам пишет код, запускает его, смотрит на ошибки и
исправляет. Ваша задача — поставить задачу словами и проверить результат.

## Что где лежит

```
data/       датасеты (только чтение, не меняйте их)
sessions/   по папке на каждую задачу: агент создаёт её сам,
            результат — в sessions/<id>/output/
example/    пример, с которого можно начать
```

Папка задачи нужна, чтобы параллельные работы не перезаписывали друг друга:
у каждого своя `sessions/<id>`, и ссылка на результат ведёт именно туда.

## Какие данные есть

Полный список с числом строк и размером — в `data/README.md`. Кратко:

```
bank.csv                 4 521 строка   отклик на депозитную кампанию (разделитель ;)
car_evaluation.csv       1 728 строк    оценка авто по 6 признакам → класс
wholesale_customers.csv    440 строк    оптовые клиенты: канал, регион, расходы
wb_*.csv          0.5–2.3 тыс. строк   20 показателей World Bank, 2015–2023, по странам
owid_*.csv         7–9 тыс. строк       ВВП на душу и ИПЦ по годам (Our World in Data)
```

Макро-файлы World Bank одинаковой формы (`country, country_code, year, показатель`),
поэтому их можно соединять по стране и году. Важно: кроме стран в них есть
42 макроагрегата (`World`, `Euro area`, `OECD members`…) — в `data/README.md`
написано, как их отбросить.

## Первые три задания

1. **Посмотреть на данные.** «Загрузи `data/bank.csv` (разделитель `;`), скажи
   сколько строк и колонок, покажи первые 5 строк и распределение `y`».

2. **Ответить на вопрос.** «По `data/wb_inflation.csv` покажи инфляцию в 2023
   по 10 странам и сравни с `data/wb_unemployment.csv`».

3. **Поймать агента на ошибке.** Дайте заведомо неверную вводную («в `bank.csv`
   10 000 строк, построй по ним график») и посмотрите, станет ли агент спорить
   или молча придумает данные. Это важнее, чем первые два пункта.

## Как разговаривать с агентом

- Формулируйте как коллеге: что нужно на выходе, а не как писать код.
- Если результат не тот — не переписывайте всё, скажите что именно не так.
- Спрашивайте «покажи код, который ты запустил» — всегда полезно.
- Агент ошибается уверенно. Проверяйте цифры.

## Чего сделать не получится

В песочнице нет интернета и нельзя ставить пакеты. Доступны `pandas`, `numpy`,
`matplotlib`, `openpyxl`. Файлы за пределами этой папки недоступны — так задумано.
