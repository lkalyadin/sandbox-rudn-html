# Инструкции для агента

Контекст: демо-стенд для студентов-экономистов. Они учатся формулировать задачи
агенту и проверять результат, а не писать код.

## Правила

- Отвечай по-русски.
- Работай только внутри рабочей папки. За её пределы не выходи.
- **Своя папка на каждую задачу.** Все студенты работают в одной общей папке
  `/work`, поэтому сначала создай себе папку задачи:
  `python3 /opt/tools/new_task.py` → напечатает `/work/sessions/<id>`. Скрипты,
  промежуточные файлы и результат держи только внутри неё, ссылка на
  результат — `/files/sessions/<id>/output/<файл>`. В общий `/work/output`
  не пиши, чужие папки в `/work/sessions/` не трогай.
- В интернета нет. Пакеты ставить нельзя. Доступно: pandas, numpy, matplotlib,
  openpyxl, стандартная библиотека Python.
- **Дашборд собирай готовым конструктором**, а не с нуля: у него уже есть
  панель настроек, сохранение автономного HTML, блок Skill.MD и проверки.
  Типовая задача по World Bank — одной командой:
  `python3 /opt/viz/kit/examples/wb_country.py --csv wb_gini.csv --title "…" --out output/dashboard.html`
  Своя задача — через `spec.json`: `python3 /opt/viz/kit/dashboard.py --spec … --out …`.
  Описание полей — `/opt/viz/kit/README.md`.
- Файлы в `/opt` и `/etc` (kit, каталог данных, Hallmark, текст Skill.MD) читай
  через `cat` или `python3`: инструмент чтения файлов на них отвечает
  `external_directory`, это граница песочницы, а не поломка.
- В `wb_*.csv` кроме стран есть 42 макроагрегата Всемирного банка (`World`,
  `Euro area`, `OECD members`, `Sub-Saharan Africa`…). Отбрасывай их через
  `sys.path.insert(0, "/opt/viz/kit"); from wb import load` — иначе «World»
  попадёт в рейтинг стран первым.
- Проверки перед ссылкой: `python3 /opt/viz/check_page.py output/dashboard.html`
  и `python3 /opt/viz/kit/verify_page.py output/dashboard.html` — по одному
  прогону, плюс один скриншот. Свои тестовые фреймворки не пиши.
- Данные лежат в `data/` и **только для чтения**: запускай код из папки задачи
  и указывай путь `/work/data/<файл>`; результаты — в `output/` своей папки задачи.
- Когда студент спрашивает «какие есть данные» — открой `data/README.md` и покажи
  файлы **с числом строк и размером** (там готовая таблица на 25 файлов), а не
  отвечай по памяти и не перечисляй три файла наугад.
- Не изменяй файлы в `data/`.
- `opencode.json` — служебный файл стенда: в нём выключена модель `big-pickle`
  (провайдер её отдаёт в списке, но при запуске отвечает «Model unavailable» —
  чтобы студенты не выбирали сломанную модель, она скрыта). Не удаляй файл и не
  правь его без просьбы студента.
  Если студент спрашивает про `longcat` — этой модели у бесплатного провайдера
  больше нет (проверено 27.10.2026), вернуть её нельзя.

## Как объяснять

- Студенты не программисты. После запуска кода коротко объясни, что получилось
  и как это читать, а не просто покажи вывод.
- Не прячь код. Если запускаешь скрипт — держи его в файле в рабочей папке,
  чтобы студент мог посмотреть и переиспользовать.
- Если в данных чего-то нет — скажи прямо. Не выдумывай цифры и не
  додумывай пропущенные значения молча.
- Если вопрос сформулирован так, что из данных нельзя получить ответ,
  скажи об этом до того, как что-то строить.

## Экономический контекст

- Для графиков: подпиши оси и единицы измерения, иначе результат бесполезен.
- Денежные величины указывай с валютой и периодом.
- Всегда говори, сколько наблюдений попало в расчёт и сколько выброшено
  и почему.
