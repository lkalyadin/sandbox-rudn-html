Инструкция
  1. В каждом вопросе выберите один правильный ответ и обведите его букву.
  2. За правильный ответ — 1 балл, за неправильный — 0. Максимум — 25 баллов.
  3. Пользоваться конспектами и ИИ-сервисами нельзя.
  4. Если вопрос кажется неоднозначным, выбирайте ответ, наиболее близкий к формулировкам лекции.
01ЗАНЯТИЕ 1

Критерий качества визуализации

В лекции сформулирован принцип MIT: визуализация — это инструмент ответа. Какой критерий показывает, что график действительно выполнен качественно?

  1. AГрафик содержит все показатели из таблицы, даже если часть из них не нужна для вопроса.
  2. BИспользованы максимально яркие цвета и объёмные эффекты.
  3. CЗритель может сформулировать ответ по данным, глядя на график.
  4. DГрафик построен в том же файле Excel, что и расчёт.

11ЗАНЯТИЕ 4

WHAT, WHY, HOW

В модели Tamara Munzner WHAT описывает данные, WHY — задачу, HOW — визуальную форму. Что относится к WHY?

  1. AСущности, атрибуты и единица наблюдения.
  2. BMarks, channels и агрегация.
  3. CПериод и база сравнения.
  4. DДействие человека: сравнить, найти, оценить.

  2. BОна не поддерживает подписи данных.
  3. CОна подходит только для временных рядов.
  4. DОна всегда искажает значения без сортировки.
13ЗАНЯТИЕ 4

Наблюдение или интерпретация

Выручка mobile снизилась на 18%, и на mobile приходится 64% общего снижения. Какой тип утверждения — «на mobile приходится 64% общего снижения»?

  1. AObservation: прямо считывается из данных.
  2. BInterpretation: требует декомпозиции вкладов.
  3. CCausal claim: доказывает причину падения.
  4. DПрогноз: требует модели.
14ЗАНЯТИЕ 5 · ЛР 06

Что CSV не хранит

Какое утверждение о CSV соответствует лекции?

  1. ACSV хранит типы столбцов, формулы и оформление.
  2. BCSV всегда использует запятую и не допускает других разделителей.
  3. CCSV поддерживает вложенные объекты и массивы.
  4. DCSV — текстовая таблица: типы данных не описаны и восстанавливаются при импорте.
15ЗАНЯТИЕ 5 · ЛР 06

Типы в XML

Какое утверждение об XML верно?

  1. AТипы значений может задавать внешняя схема XSD.
  2. BXML не может задавать типы данных ни при каких условиях.
  3. CXML хранит данные только в виде массива.
  4. DXML — бинарный формат, нечитаемый человеком.
16ЗАНЯТИЕ 5 · ЛР 06

Типы в JSON

Какое утверждение о JSON соответствует лекции?

  1. AJSON поддерживает только строки и числа.
  2. BJSON не поддерживает вложенность.
  3. CJSON поддерживает 6 типов значений, а дата обычно хранится строкой.
  4. DJSON хранит формулы и стили ячеек.

21ЗАНЯТИЕ 6

Уровень проверки: нет валюты

Правило: валюта обязательна. В строке 2 счёта валюта не заполнена (∅). К какому уровню проверок L1–L4 относится нарушение?

  1. AL2 · Conformity — проверка формы значения.
  2. BL1 · Completeness — проверка обязательности значения.
  3. CL3 · Consistency — сверка со справочником.
  4. DL4 · Accuracy & Integrity — проверка связей и бизнес-правил.

В поле «Статус» стоит PADI, допустимые значения — ISSUED, PAID, CANCELLED. Какая проверка ловит ошибку?

  1. AL1 · Completeness

  3. CL4 · Key constraints
  4. DL2 · Restricted values — допустимый набор значений.

24ЗАНЯТИЕ 6

Действие по результату проверки

Правило: тип «Внешний» должен составлять наибольшую долю клиентов. Факт: внешних 40%, группа 60%. Какое действие предусмотрено?

  1. AReject — удалить строки и пересчитать отчёт.
  2. BPass — ошибки нет, правило необязательное.
  3. CFlag & Pass — сохранить данные с предупреждением и выяснить причину.
  4. DИсправить тип клиента вручную, чтобы доля стала 60%.
25ЗАНЯТИЕ 6

SQL-инъекция и prompt injection

В лекции различают SQL-инъекцию и prompt injection. В чём ключевое различие?

  1. AЭто одно и то же, только для разных СУБД.
  2. BSQL-инъекция внедряет код в запрос к базе, prompt injection — скрытые указания в данных или документе для ИИ-агента.
  3. CPrompt injection атакует базу данных, SQL-инъекция — языковую модель.
  4. DSQL-инъекция возможна только через API, prompt injection — только через Excel.
